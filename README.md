# عزم | AZM — منصة إدارة المشروعات

الإنماء الحر للمقاولات

منصة إدارة مشروعات المقاولات والتحكم في تكلفتها. الإصدار الحالي هو **المرحلة الأولى: الحسابات والصلاحيات والمشروعات وطواقمها**.

## ما يشمله هذا الإصدار

- **الحسابات:**
  - الأدمن (الكوست كنترول) وحده ينشئ الحسابات، باسم مستخدم وكلمة مرور مؤقتة.
  - كل حساب له كود ثابت بصيغة `USR-الدور-مسلسل`، مثل `USR-PM-03`.
- **أول دخول:** تغيير كلمة المرور المؤقتة إجباري قبل استخدام أي صفحة.
- **الأمان:**
  - كلمات المرور مشفرة (scrypt)، وما حدش يقدر يشوفها، حتى الأدمن.
  - قفل الحساب 15 دقيقة بعد 5 محاولات خاطئة.
  - الجلسات محفوظة على الخادم: تنتهي بعد ساعتين خمول، أو 12 ساعة كحد أقصى.
  - الرسالة عند الخطأ واحدة سواء كان اسم المستخدم غلط أو كلمة المرور، فما حدش يقدر يعرف الحسابات الموجودة.
  - حماية CSRF على كل النماذج.
- **إدارة الحسابات:** تعديل الدور والبيانات، إسناد المشروعات، إعادة تعيين كلمة المرور، إيقاف الحساب أو إعادة تفعيله.
  - إيقاف الحساب أو تغيير دوره ينهي جلساته فورًا.
  - ما ينفعش يتوقف آخر أدمن، ولا يوقف الأدمن نفسه.
- **الأدوار:**
  - طاقم الشركة: الكوست كنترول (أدمن)، مدير مشروع، الدايركتور، المحاسب، مشاهد (إدارة عليا).
  - أطراف المشروع: ممثل المالك، الاستشاري.
- **المشروعات:**
  - كود تلقائي بصيغة `P-السنة-مسلسل`.
  - بيانات العقد الرئيسي: رقم العقد، القيمة، تاريخ البداية والنهاية.
  - إسناد الطاقم للمشروع.
  - كل مستخدم يشوف المشروعات المسندة له بس. الأدمن والدايركتور والمشاهد يشوفوا كل المشروعات.
- **سجل العمليات:** للإضافة فقط. ما ينفعش يتعدل أو يتحذف، حتى من قاعدة البيانات مباشرة.
- **الصلاحيات:** بتتفحص على الخادم في كل طلب، مش في الواجهة بس.

## النشر على Vercel مع Supabase

قاعدة البيانات على Supabase (PostgreSQL)، والتطبيق على Vercel كـ Python Function (`api/index.py` و `vercel.json`).

**1. قاعدة البيانات:** المهاجرات في `app/migrations/postgres/` وتتطبق تلقائيًا عند أول تشغيل، أو يدويًا:
```bash
python manage.py migrate      # يقرأ DATABASE_URL من .env.local
```
الجداول كلها عليها RLS ومقفولة أمام مفاتيح Supabase العامة (anon). التطبيق وحده يتصل بقاعدة البيانات مباشرة.

**2. متغيرات البيئة على Vercel** (Project → Settings → Environment Variables):

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | رابط Supabase من Connect → **Transaction pooler** (المنفذ 6543)، مع `?sslmode=require`. الرابط المباشر `db.xxx.supabase.co` لا يعمل على Vercel لأنه IPv6 فقط |
| `CC_SECRET_KEY` | مفتاح عشوائي ثابت، وهو إلزامي مع Postgres |
| `CC_SETUP_TOKEN` | رمز صفحة الإعداد الأول |

باقي المتغيرات اختيارية وقيمها الافتراضية مناسبة لـ Vercel (`CC_PLATFORM_NAME`، `CC_COMPANY_NAME`، `CC_SESSION_*`).

**3. النشر:** اربط المستودع بـ Vercel (Framework Preset: Other)، أو استخدم `vercel --prod`.

**4. أول أدمن:** افتح `https://YOUR-APP.vercel.app/setup?token=CC_SETUP_TOKEN`.

ملاحظة: Vercel يرفض الطلبات الأكبر من 4.5 ميجا، فملف Excel للاستيراد لازم يكون أصغر من كده.

## التشغيل على السيرفر (VPS)

المطلوب: سيرفر Linux (Ubuntu 22.04 أو أحدث)، ودومين موجّه لعنوان السيرفر.

**1. تثبيت Docker و nginx:**
```bash
curl -fsSL https://get.docker.com | sh
sudo apt install -y nginx certbot python3-certbot-nginx
```

**2. رفع الملفات وتجهيز الإعدادات:**
```bash
cd /opt && sudo mkdir costcontrol && sudo chown $USER costcontrol
# انسخ محتوى المشروع إلى /opt/costcontrol
cd /opt/costcontrol
cp .env.example .env
python3 -c "import secrets; print(secrets.token_hex(32))"   # ضع الناتج في CC_SECRET_KEY داخل .env
mkdir -p data && sudo chown 1001 data
```

**3. التشغيل:**
```bash
docker compose up -d --build
```

**4. إنشاء حساب الأدمن الأول:**
ضع رمزًا سريًا في `.env` بالسطر `CC_SETUP_TOKEN=رمز-طويل-عشوائي`، ثم `docker compose up -d`، وافتح:
`https://YOUR-DOMAIN/setup?token=رمز-طويل-عشوائي`
واملأ بيانات الأدمن. صفحة الإعداد تقفل نفسها تلقائيًا بعد إنشاء أول أدمن.

**5. ربط الدومين وتفعيل HTTPS:**
```bash
sudo cp deploy/nginx.conf /etc/nginx/sites-available/costcontrol
sudo sed -i 's/cost.example.com/YOUR-DOMAIN/' /etc/nginx/sites-available/costcontrol
sudo ln -s /etc/nginx/sites-available/costcontrol /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d YOUR-DOMAIN
```

بعد كده افتح `https://YOUR-DOMAIN` وادخل بحساب الأدمن.

## التجربة على جهاز ويندوز

1. ثبّت Python من python.org، وعلّم على **Add python.exe to PATH**.
2. دبل كليك على **start-windows.bat**.
3. المتصفح يفتح على `http://127.0.0.1:5000`. أول مرة تظهر صفحة إنشاء حساب الأدمن.

## النسخ الاحتياطي

قاعدة البيانات ملف واحد: `data/costcontrol.sqlite3`. لأخذ نسخة سليمة والموقع شغال:
```bash
sqlite3 data/costcontrol.sqlite3 ".backup 'backup-$(date +%F).sqlite3'"
```
يُفضل جدولتها يوميًا بـ cron، ونقل النسخ خارج السيرفر.

## أوامر الإدارة

| الأمر | الوظيفة |
|---|---|
| `python manage.py create-admin` | إنشاء حساب أدمن |
| `python manage.py unlock USERNAME` | فك قفل حساب قبل انتهاء الـ 15 دقيقة |
| `python manage.py migrate` | تطبيق تحديثات قاعدة البيانات (تتم تلقائيًا عند التشغيل) |

## المراحل القادمة

1. جدول الكميات (BOQ) وهيكل WBS وأكواد البنود وتسعيرها.
2. الخطة الزمنية وربطها بالبنود والتكلفة.
3. النطاقات المختصرة وتقديرات مدير المشروع، ثم اعتماد خط الأساس.
4. سلسلة تنفيذ البند: بدء التنفيذ ومؤشر التأخير، النطاق التفصيلي، سجل الموردين واعتمادهم، العروض (عرضين على الأقل)، الترشيح، طلب أمر التشغيل، اعتماد الكوست كنترول ثم الدايركتور، إصدار العقد وتوقيعه.
5. طلبات الصرف (حد الدايركتور 10,000 ريال)، والتحويلات البنكية بالإيصال، والإشعارات بالبريد.
6. دليل أصناف أعمال البناء (أكثر من 10,000 صنف).
